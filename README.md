# 时空围棋 · TimeGo

一个零后端依赖、纯 JavaScript + HTML5 Canvas 实现的围棋变体网页游戏。在 25×25 棋盘上加入了**时间旅行**机制：回溯权、时间债务、时痕子、时间线分岔与修复、毁灭性共振。

直接用浏览器打开 `index.html` 即可游玩，无需任何服务器、无需构建步骤、无需联网。

---

## 项目简介

- 棋盘：25×25，列标 A–Y，行标 1–25。
- 黑方先手；贴目 6.5（白方 +6.5）。
- 默认模式：人机对战（玩家执黑，白方为 MCTS AI）。可切换为双人本地对战。
- 完全离线运行，兼容 `file://` 直接打开，也兼容 GitHub Pages 部署。

## 如何运行

### 方式一：直接打开
双击 `index.html`，或在浏览器地址栏输入 `file:///.../timego/index.html`。

### 方式二：GitHub Pages
将整个 `timego` 目录推到 GitHub 仓库，在仓库 Settings → Pages 中选择分支与根目录，访问生成的 `https://<用户>.github.io/<仓库>/index.html` 即可。

> 注意：本游戏使用相对路径加载 `static/*.js` 与 `static/style.css`，且使用普通 `<script>` 标签（非 ES module），因此 `file://` 与 `https://` 均可正常工作。

## 规则摘要

### 1. 基础围棋（25×25）
- 气、群、提子：BFS 计算群与气；落子后提走对方无气群的普通子。
- 禁自杀：使己方群无气且未提子的着法非法。
- 超级劫：禁止在当前时间线内再现任何历史完整局面。

### 2. 回溯权与时间债务
- 双方初始回溯权为 0。每提 1 颗对方子获得 +1 回溯权（可累加）。
- 回合内可消耗 1 回溯权进行「时间回溯」代替普通落子。只能回溯到自己下过、且未被锁定的手。
- 回溯权为 0 时可透支，最多 3 笔债务，并标记「追偿点 = 当前手数 + 20」。
- 处于债务时，提子先偿债（每提 1 子抵 1 债，再发回溯权）。追偿点到仍欠债则跳过本手（对手连下两手），之后每 10 手再追偿一次。
- 终局时剩余债务：每笔扣 3 分地域。

### 3. 时痕子（时痕子）
- 拥有普通子的属性（供气、连接、做眼），但**永不可被提**。
- 计分：时痕子所占点 = 0 分；仅被时痕子围住的空区 = 0 分。
- 寿命周期（按出生后的手数计）：
  - 稳定 0–20：功能完整，不可提。
  - 惰性 21–40：仍不可提，但不供气、不连接。
  - 湮灭 41+：自动消失，交点变空。
- 充能：回溯落子若落在某时痕子正交相邻 4 格内，将其寿命重置为稳定。
- 母手绑定：时痕子绑定其回溯母手；母手被「锁定为既定事实」时，时痕子立即湮灭。

### 4. 时间线分岔与修复
- 分岔：回溯落点若为对方子，则从母手局面新建一条时间线，回溯子作为普通子落入新时间线；原时间线冻结，战场切换到新时间线。
- 修复：新时间线中，若对方提走引发分岔的那颗普通子，则战场回到原时间线，原时间线第 1..分岔点手被锁定为既定事实，提子那手也锁定，新时间线其余着手作废。

### 5. 毁灭性共振
- 每次落子/提子/修复后扫描全部时痕子。若同一直线（横/竖/斜，任意间距）上存在 ≥3 颗时痕子，则该线上所有棋子被抹除并化为**永久空洞**（任何子都不可再落于此），不可逆。

### 6. 终局与计分
- 结束条件：认输；或一方既无合法着又无法回溯；或双方连续弃权后声明终局。
- 计分：空区只被一种颜色围住则归该色（地域计分）。时痕子点 = 0；仅时痕子围住的空区 = 0。扣除债务罚分（债务 ×3）。白方加贴目 6.5。地域多者胜。

## AI（白方）
- 基于 MCTS（无神经网络）：候选着生成于已有子周围曼哈顿距离 ≤2 的空点；UCB1 选择；快速模拟为贪心+随机。
- 模拟中按规则简化：忽略分岔/修复，时痕子按普通子处理。
- 异步分块运行，界面显示「思考中…」，每手数秒内返回。
- 人机模式下轮到白方自动触发。

## 操作说明

- **落子**：鼠标点击棋盘交点。
- **回溯**：点击「回溯」按钮 → 在右侧「着手记录」中点击一个**自己下过的手**作为母手 → 在棋盘上点击目标交点：
  - 空点 / 己方子 → 放置时痕子；
  - 对方子 → 触发时间线分岔。
- **弃权**：跳过本手。
- **认输**：当前方认输。
- **声明终局**：结束对局并按规则计分（建议在双方连续弃权后使用）。
- **模式切换**：在人机对战 / 双人本地对战之间切换。
- **新对局**：重置棋局。
- **时间线**：右侧时间线列表中点击某条可切换查看（落子仍在活动时间线）。

## 界面元素

- 普通子：黑色 / 白色圆子。
- 时痕子：带光晕的半透明子，中央数字表示距下一衰减阈值的剩余手数（绿色=稳定，红色=惰性）。
- 永久空洞：黑色叉号。
- 上一手：红色小圆圈高亮。

## 关于 Python 服务端版本

本目录为纯前端版本，开箱即用。若需要在线联机版本，可参考独立的 `server/server.py`（不在本目录内，需另行部署），它提供 SocketIO 房间与对局同步；默认离线游玩不依赖该服务。

## 已知简化

为兼顾可玩性与性能，在符合规则允许的范围内做了如下简化：
- AI 在模拟中忽略分岔/修复，时痕子按普通子处理（规则明确允许）。
- AI 默认仅进行普通落子，不主动使用回溯（玩家可充分体验回溯/分岔机制）。
- 超级劫判定基于局面哈希（含时痕子类型，不含寿命）。
